# Python Programming Course

Week 1 (programming) of the PALOP course, *Quantitative Skills for Biology*: a five-day introduction to Python for biologists, using biological examples throughout (sequences, gene expression, differential expression).

The notebooks are written to run in Jupyter or Google Colab.

## Schedule

| Day | Topic | Notebook | Exercises | Slides |
|-----|-------|----------|-----------|--------|
| 1 | Python basics | `day1_python_basics.ipynb` | `Exercises/exercises_day1.ipynb` | `Slides/Day1_Python_Basics.pptx` |
| 2 | Control flow and functions | `day2_control_flow_functions.ipynb` | `Exercises/exercises_day2.ipynb` | `Slides/Day2_Control_Flow.pptx` |
| 3 | Data structures and file I/O | `day3_data_structures_files.ipynb` | `Exercises/exercises_day3.ipynb` | `Slides/Day3_Data_Structures.pptx` |
| 4 | NumPy and pandas | `day4_numpy_pandas.ipynb` | `Exercises/exercises_day4.ipynb` | `Slides/Day4_NumPy_Pandas.pptx` |
| 5 | Visualisation (Matplotlib, seaborn) | `day5_visualisation.ipynb` | `Exercises/exercises_day5.ipynb` | `Slides/Day5_Visualization.pptx` |

## Contents

- `Introduction_Jupyter.ipynb`: introduction to Jupyter and Python basics.
- `dayN_*.ipynb`: the teaching notebook for each day.
- `Exercises/`: exercise notebooks for each day.
- `exercises.ipynb`: extra sequence exercises (GC content, complement, transcription, reverse, translation).
- `Slides/`: lecture slides for each day.
- `Notebooks_Joao/`: alternative versions of the day notebooks.

## Requirements

Python 3 with Jupyter, NumPy, pandas, Matplotlib and seaborn. No installation is needed on [Google Colab](https://colab.research.google.com/).
